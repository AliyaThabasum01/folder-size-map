# 📦 Folder Size Map

A lightweight Python CLI tool that analyzes a folder and displays its files sorted by size.

## Features

- Scan folders recursively
- Display file sizes
- Sort files from largest to smallest
- Show relative file paths
- No external dependencies

## Run

```bash
python main.py
```

## Example

```text
📦 Folder Size Map
========================================

Enter folder path: ./project

📊 Files by size:

    245.60 KB  data.csv
     84.32 KB  assets/image.png
     12.10 KB  README.md
      3.45 KB  main.py
```
